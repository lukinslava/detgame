# Сыскное бюро

Кооперативный карточный детектив для компании из 1–6 человек. В него можно играть с разных устройств, в том числе с телефонов. Механика вдохновлена серией «Детективные хроники» (Decktective), но дело и все тексты в игре оригинальные.

## Дела

Ведущий выбирает дело в комнате ожидания.

| Дело | Сложность | О чём |
|---|---|---|
| Ночной экспресс | Лёгкое | 1913 год, убийство в запертом купе спального вагона |
| Выстрел в третьем акте | Среднее | 1926 год, премьер театра убит на сцене из бутафорского нагана |
| Именины в метель | Сложное | 1899 год, помещик убит в своём кабинете, и один из подозреваемых сознаётся |
| Полярная ночь | Очень сложное | 1975 год, метеоролог погиб у приборов на полярной станции |

Чем сложнее дело, тем больше в нём виновных, ложных признаний, лгущих свидетелей и ловушек со временем.

## Как играть

1. Один человек открывает сайт и нажимает «Создать комнату». Он становится ведущим.
2. Он отправляет друзьям ссылку или код комнаты из 5 символов.
3. Когда все в комнате, ведущий нажимает «Начать расследование».
4. Каждый получает карты на руку. Показывать и пересказывать их нельзя, но заголовки чужих карт видны всем.
5. В свой ход игрок делает одно из двух:
   - **выкладывает карту на стол**, где её читают и обсуждают все. Это можно сделать, только если число на карте не больше, чем карт в архиве;
   - **отправляет карту в архив**. Её никто не прочтёт до конца игры, зато открываются карты с большими числами.
6. Потом игрок берёт карту из колоды. Повороты сюжета открываются сразу всем.
7. После карты «Дело закрыто» доигрываются карты с рук. Затем все вместе отвечают на вопросы следователя, получают очки и читают разгадку.

Обсуждать карты можно во встроенном чате или голосом.

## Как это устроено

- Обычный статичный сайт: HTML, CSS и JavaScript без сборки.
- Устройства связываются через публичный MQTT-брокер по WebSocket (по умолчанию `broker.hivemq.com`). Свой сервер не нужен, связь работает и через мобильный интернет.
- Состояние игры хранит браузер ведущего. Ему **нельзя закрывать вкладку**. Если он перезагрузит страницу, игра продолжится с того же места.
- Если игрок потерял связь или перезагрузил страницу, он возвращается на своё место автоматически.
- Если игрок вылетел и зашёл с другого телефона или браузера, он открывает ту же ссылку и выбирает своё имя в списке. Карты остаются при нём. Занять можно только место игрока, который сейчас не в сети.
- Если игрок не возвращается, ведущий может пропустить его ход или раздать его карты остальным и доиграть без него. Если игрок потом вернётся, он доберёт карты из колоды.
- Пока идёт игра, страница просит телефон не гасить экран: во сне браузер рвёт соединение.
- Скрытность карт держится на честности: тексты карт лежат в коде страницы, как и в коробке с настольной игрой.

Другой брокер можно указать параметром: `?broker=wss://адрес/mqtt`. Он должен быть одинаковым у всех игроков, и ссылка-приглашение передаёт его сама.

## Публикация на GitHub Pages

Settings → Pages → Build and deployment → Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)**. Через минуту сайт будет доступен по адресу `https://<логин>.github.io/detgame/`.

## Разработка

```bash
python3 -m http.server 8080   # затем открыть http://localhost:8080
npm test                      # тесты игровой логики (Node 18+)
```

Файлы:

- `js/cases/*.js` — дела: карты, вопросы, разгадка, схема места преступления;
- `js/cases/index.js` — список дел и уровней сложности;
- `js/engine.js` — правила игры (чистые функции, покрыты тестами);
- `js/net.js` — сетевой слой поверх MQTT;
- `js/main.js` — интерфейс;
- `vendor/mqtt.min.js` — браузерная сборка [MQTT.js](https://github.com/mqttjs/MQTT.js) 5.16.1 (MIT).

Новое дело — это новый файл в `js/cases/` в том же формате, добавленный в `js/cases/index.js`. Порядок карт в колоде важен: колоду не перемешивают. Тесты в `tests/cases.test.mjs` проверяют каждое дело: карты, вопросы, схему и прогон партий на 1–6 игроков.
