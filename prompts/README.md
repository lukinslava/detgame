# Промпты для картинок

Здесь промпты для нейросетей: по одному на каждую карту и обложку дела, всего 177. Готовые картинки заменят векторные рисунки в игре.

- [Ночной экспресс](night-express.md) — 45 карт
- [Выстрел в третьем акте](last-act.md) — 41 карта
- [Именины в метель](snow-estate.md) — 43 карты
- [Полярная ночь](polar-night.md) — 44 карты
- [Всё одной таблицей](prompts.csv) — для пакетной генерации

## ChatGPT: стиль одним сообщением

Для ChatGPT есть отдельные файлы в папке [chatgpt/](chatgpt/), по одному на дело.

1. Откройте **новый чат** для дела и отправьте **первое сообщение** из файла целиком. Оно задаёт стиль, формат 3:2, эпоху и внешность всех персонажей. В ответ ChatGPT нарисует обложку, и она станет образцом стиля.
2. Дальше присылайте **карточки по одной**: короткое описание сцены, где персонажи названы по именам. Их внешность ChatGPT берёт из первого сообщения.
3. Если стиль поплыл или картинка вышла квадратной, напишите «Держи тот же стиль, что у обложки, горизонтальный формат 3:2» и пришлите карточку ещё раз. Если на картинке появились буквы — «То же самое, но без текста».

Одно дело — один чат: так ChatGPT помнит и стиль, и персонажей.

## Другие нейросети

Полные промпты (в файлах выше) самодостаточны: стиль и внешность персонажей вписаны в каждый. Они на английском, так их лучше понимают Midjourney, DALL·E, Leonardo и Stable Diffusion. Kandinsky и Шедеврум тоже их понимают.

- **Формат — широкий, примерно 2:1.** В Midjourney добавьте в конец промпта `--ar 2:1 --style raw`. В DALL·E выберите широкий формат (1792×1024). В других генераторах — «пейзажный» формат.
- **Стиль уже в каждом промпте:** старинная гравюра, сепия на состаренной бумаге, нуар, без надписей. Не убирайте эту часть, иначе картинки разных карт будут разного вида.
- **Персонажи.** Описание внешности подставлено во все карты персонажа, чтобы он везде был похож на себя. В Midjourney можно ещё надёжнее: сгенерируйте первый портрет и добавляйте его к следующим промптам этого персонажа через `--cref <ссылка на картинку>`.
- **Надписи.** Нейросети плохо пишут по-русски, поэтому в промптах стоит «no text». Если на картинке всё же появились буквы — перегенерируйте.
- **Тела и раны** описаны сдержанно («tasteful, no gore»). Некоторые сервисы всё равно могут отказать — тогда уберите из промпта слово про тело или кровь.

## Куда класть картинки

Во входящие: [img/inbox/](../img/inbox/), по папке на дело. Загрузить можно прямо на GitHub: **Add file → Upload files**. Называйте файлы по номеру карты (`c01.png`), обложку — `cover.png`.

Дальше Claude запускает `python3 tools/import_images.py`. Скрипт сжимает картинки для телефона, кладёт их в `img/<дело>/<id>.jpg` и включает в `js/images.js`. Карты без картинки остаются с векторным рисунком, поэтому добавлять можно постепенно.

## Как поменять промпты

Исходники — в `prompts/src/<дело>.mjs`: описание эпохи, внешность персонажей и сюжет каждой карты. После правки пересоберите файлы командой `npm run prompts`. Тест `tests/prompts.test.mjs` проверяет, что у каждой карты есть промпт.
