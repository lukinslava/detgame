# Входящие картинки

Сюда складывайте картинки из ChatGPT. Claude заберёт их и вставит в игру.

Каждому делу — своя папка:

- [Ночной экспресс](night-express/) — карты c01…c45
- [Выстрел в третьем акте](last-act/) — карты m01…m41
- [Именины в метель](snow-estate/) — карты h01…h43
- [Полярная ночь](polar-night/) — карты p01…p44

## Как загрузить

1. Откройте папку нужного дела.
2. Нажмите **Add file → Upload files** и перетащите или выберите картинки. С телефона тоже работает.
3. Внизу нажмите **Commit changes**.

## Как называть файлы

По номеру карты: `c01.png`, `c02.jpg`… Обложку дела — `cover.png`. Номера указаны у каждой карточки на странице с промптами.

Если не успели переименовать — тоже можно: Claude разберёт картинки по содержанию. Просто это дольше, и он может спросить про спорные.

Подойдут PNG, JPG и WEBP любого размера: картинки потом сожмутся для телефона автоматически.
